# ⚾ KBO 매니저 2026 — 감독 시뮬레이터

FM 스타일의 KBO 야구단 운영 시뮬레이션 **웹앱**입니다. 빌드 도구 없이 브라우저에서 바로 실행됩니다.

## 실행 방법
```
# 그냥 index.html 더블클릭으로 열거나, 로컬 서버 권장:
python3 -m http.server 8000
# → http://localhost:8000 접속
```
진행 상황은 브라우저 `localStorage`에 자동 저장됩니다 (이어하기 지원).

## 구현된 기능
- **팀 선택 화면**: 10개 구단 종합 오버롤 + 난이도 + 가용 예산(억 원) 표시. 프리시즌부터 시작.
- **선수 데이터**: 사용자가 제공한 2026 시즌 10개 구단 **628명** 전원 반영.
  - 종합스탯 50~80, 현재/최고(잠재) 스탯, 나이 보유
  - 세부스탯 자동 산출 — 타자: 파워·주루·컨택·수비 / 투수: 구속·제구·구위
  - 포지션 숙련도 A~E (주포지션 A, 보조 B·C·D, 불가 E)
- **로스터 관리**: 1군 28인 엔트리, 콜업/말소(전 구단 동일), 1군/2군 출전 제한, 이력 기록.
- **경기 진행**: 경기 전 라인업·선발 편성 → 타석 단위 "진행". 대타/대수비/투수교체 언제든 가능.
  - 투수 피로·연투, 선발 4일 휴식, 부상(현실적 빈도), 실책·도루·병살·희생플라이 등 변수
  - KBO 규칙: DH, 9이닝, 9회 이후 끝내기, 12이닝 무승부
- **2군 자동 시뮬**: 1군 경기 후 우리 2군 결과·주요 활약 리포트.
- **리그 운영**: 타 구단도 동일 규칙(콜업/말소·부상·AI 투수운용). 정규 144경기 일정.
- **기록 관리**: 타율·OPS·홈런·타점·도루 / ERA·WHIP·홀드·세이브·다승 누적 리더보드.
- **성장/감소**: 24세 이하 유망주 성장, 33세 이상 노쇠화(월간·낮은 빈도). 포지션 훈련(연관 포지션만).
- **트레이드**: 마감일(7/31) 내 선수 거래, AI 가치 평가 수락/거절, 즉시 로스터 반영.
- **뉴스**: 타 구단 포함 부상·이적·성장 등 주목할 소식 보고.
- **포스트시즌**: 와일드카드 → 준PO → PO → 한국시리즈 (KBO 방식).
- **팀 미팅**: 경기 전/후 소집으로 사기(폼) 변동.

## 파일 구조
```
index.html        화면 셸
css/style.css     스타일
js/data.js        10개 구단 원천 로스터 데이터
js/players.js     세부스탯·숙련도·역할 산출
js/schedule.js    시범경기 + 정규 144경기 일정 생성
js/engine.js      타석 단위 경기 시뮬레이션 엔진
js/game.js        리그 운영(로스터·AI경기·2군·뉴스·성장·트레이드·포스트시즌·저장)
js/ui.js          화면 렌더링 및 상호작용
```

> 선수 스탯은 사용자가 제공한 현재/최고 종합스탯과 나이를 기반으로 결정론적으로 산출되었습니다.
